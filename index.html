Sort a card list by color

White, Blue, Black, Red, Green, Multicolor, Colorless, then Lands: the way most sellers file a binder or a box.

Drop in a CSV from ManaBox, Moxfield, Deckbox, TCGplayer, or a spreadsheet. Each card is looked up on Scryfall by its Scryfall ID, its set code and collector number, or its name, so the list doesn't need colors in it. You get back the same file, rows reordered, with a Scryfall ID and a Color Group column.

Your file stays in your browser. Only the card identifiers are sent, to Scryfall.

Big inventory? Use a Scryfall bulk file

If you’re sorting thousands of cards, or doing this every week, grab Scryfall’s bulk data once and every card gets looked up right here on your computer instead of asked for over the internet.

  1. 1) Go to Scryfall’s bulk data page.
  2. 2) Download Default Cards. It’s every printing, in English where there is one, and it’s a few hundred MB. Not Oracle Cards (one printing per card, so your exact printings won’t match), and not Rulings.
  3. 3) Pick that file here. It stays in your browser, same as your CSV.

Scryfall rebuilds these every day. Anything printed after your download still gets looked up the normal way, so you only need a fresh copy when a new set drops.
